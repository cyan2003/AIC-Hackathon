# Zero-Hallucination Recruiter Agent - Run Guide

This guide details how to set up, run, and verify the **Zero-Hallucination Recruiter Agent** pipeline and its associated services, including the Streamlit UI and the Codebase Visualizer.

---

## 📋 System Prerequisites

Before running the application, make sure your system has the following installed:

1. **Python 3.12** (Verify with `python --version`)
2. **Docker Desktop** (Required to run the local Qdrant Vector Database)
3. **Node.js & npm** (Required to run the codebase knowledge graph visualizer dashboard)

---

## 🗄️ Step 3: Run the Qdrant Vector Database

The application utilizes Qdrant as its high-performance vector store with a two-collection architecture (`resumes` and `job_descriptions`).

Start Qdrant locally in a Docker container by running:
```powershell
docker run -p 6333:6333 -p 6334:6334 qdrant/qdrant
```

This will expose the Qdrant REST API on port `6333` and gRPC on port `6334`.

---

## 🚀 Step 4: Run the FastAPI Backend Service

The core of the system is the FastAPI backend, which handles text validation, parsing (PDF/DOCX), section-aware chunking, hybrid retrieval (Qdrant vector + BM25 lexical), rank fusion, cross-encoder reranking, and LLM orchestration.

From the `zero-hallucination-rag` directory (with virtual environment activated), start the backend:
```powershell
uvicorn api.main:app --reload
```

*   **API Service URL**: `http://localhost:8000`
*   **Interactive API Docs (Swagger UI)**: `http://localhost:8000/docs`
*   **Alternative API Docs (ReDoc)**: `http://localhost:8000/redoc`

---

## 💻 Step 5: Run the Streamlit User Interface

The application features a premium Streamlit dashboard to interact with the backend service visually.

In a **new terminal tab/window** (with virtual environment activated, from `zero-hallucination-rag` directory):
```powershell
streamlit run ui/app.py
```

Streamlit will start and automatically open the application UI in your default web browser (usually at `http://localhost:8501`).

### 💡 How to Demo / Match Candidates in the UI:
1. **Upload Job Descriptions**: On the sidebar, upload one or more JD files (PDF or DOCX format).
2. **Upload Resumes**: Upload one or more candidate resumes.
3. **Select Top-K**: Use the slider to specify how many matching JDs to return per candidate.
4. **Run Recruiter Agent**: Click the primary button. The UI will:
   - Automatically ingest and parse the JDs first.
   - Run the candidate matching pipeline.
   - Display a premium visualization showing matched JDs, match confidence percentage, strengths, gaps, and exact cited passages from the resume to back up the score with zero hallucinations.

## 🔍 Step 6: Run the Codebase Visualizer (Understand-Anything Dashboard)

The project includes an interactive **Codebase Knowledge Graph** generated by the `Understand-Anything` agent plugin, which maps the file dependencies, function relationships, and business domains.

To run the interactive dashboard UI for this knowledge graph:

1. Open your terminal at the **project root directory** (where the `.understand-anything/` folder is located):
   ```powershell
   cd c:\Users\Damien\OneDrive\Desktop\AIC-Hackathon
   ```

2. Run the visualizer CLI server using `npx`:
   ```powershell
   npx understand-anything serve
   ```

3. The dashboard server will start, read the pre-analyzed graph data, and open the interactive visualization interface in your browser (typically at `http://localhost:3000` or a similar port). You can pan, zoom, click nodes to view details, and explore the architecture visually.
